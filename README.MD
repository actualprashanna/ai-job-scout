# 🎯 AI Job Scout 
> **Universal Gemini-Powered Web Aggregator & CV Matcher**

AI Job Scout transforms how people find employment across every industry worldwide—from manual laborers and teachers to corporate lawyers and executives.

### 🔑 Key Features
* 🧠 **Universal Input Transformer**: Converts raw, natural language requests into optimized search engine dorks using Gemini 1.5 Flash.
* 🌐 **Live Internet Crawling**: Aggregates fresh job listings directly from target career portals and global boards.
* 📄 **30%–100% CV Fit Analyzer**: Reads uploaded candidate resumes (PDF) and computes precise fit percentages with key strengths and missing skill breakdowns.
* ⚡ **Real-Time Indexing**: Powered by Django REST Framework, Elasticsearch, and React for instant filtering and updates.
